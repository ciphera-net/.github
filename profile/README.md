# Ciphera

**Privacy-first infrastructure, built in Belgium.**

Ciphera BV builds privacy tools that don't compromise:

- **[Pulse](https://pulse.ciphera.net)** — cookieless, GDPR-native web analytics ([live demo](https://pulse.ciphera.net/demo))
- **[Ciphera ID](https://ciphera.net/products/id)** — zero-knowledge authentication built on OPAQUE
- **[Captcha](https://ciphera.net/products/captcha)** — privacy-preserving bot protection
- **[Relay](https://ciphera.net/products/relay)** — transactional email infrastructure
- **[Tessera](https://github.com/ciphera-net/tessera)** — open-source OPAQUE SDKs: [Rust](https://github.com/ciphera-net/tessera) · [Go](https://github.com/ciphera-net/tessera-go) · [TypeScript](https://github.com/ciphera-net/tessera-ts)
