# Ciphera

**Privacy-first infrastructure, built in Belgium.**

Ciphera BV builds privacy-first tools for the web and runs them on Swiss infrastructure:

- **[Pulse](https://pulse.ciphera.net)**: cookieless, GDPR-native web analytics ([live demo](https://pulse.ciphera.net/demo))
- **[Ciphera ID](https://ciphera.net/trust#sign-in)**: zero-knowledge authentication built on OPAQUE
- **[Tessera](https://github.com/ciphera-net/tessera)**: open-source OPAQUE SDKs in [Rust](https://github.com/ciphera-net/tessera) · [Go](https://github.com/ciphera-net/tessera-go) · [TypeScript](https://github.com/ciphera-net/tessera-ts)
